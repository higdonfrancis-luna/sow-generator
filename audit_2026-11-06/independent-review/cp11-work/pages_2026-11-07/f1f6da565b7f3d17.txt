## Deploy a concierge 

Last update: October 2, 2026 

Deployment makes a concierge available to real website visitors. The marketer configures the deployment settings, while the IT or analytics team provides the datastream ID and the website team installs the deployment script on the website. 

Deployment is typically a short, one-time configuration for each site. Plan for approximately 15 minutes on the marketer’s side, plus the time required for the website team to install the script. 

 IMPORTANT 

Involve the IT or analytics team and the website team early. Their participation is required to provide the datastream ID and install the script, so deployment should not be treated as the final step of the implementation. 

## Before you begin 

- Coordinate with the IT or analytics team to obtain a datastream ID. 

- Identify the team responsible for the website or tag manager. This article refers to this group as the website team. 

- Decide whether the concierge should appear as a component on existing pages or as a complete, dedicated page. 

- Identify the domains and page paths where the concierge should appear. 

## Configure the datastream 

A datastream is the destination for activity data generated by visitor interactions with the concierge. Examples of these interactions include clicks, form submissions, booked meetings, and live chats. The datastream allows this activity to be viewed in Analytics later. 

You do not need to build a datastream as part of this procedure. You only need its ID. 

## Obtain the datastream ID 

Ask the IT or analytics team for the datastream ID. The ID can be found in Adobe Experience Platform under Data Collection > Data Streams . 

## Add the datastream configuration 

- 

Have the datastream ID ready. 

- 

In the Brand Concierge deployment section, select Add Config . 

- 

Paste the datastream ID. 

- 

Save the configuration. 

- 

After the configuration is saved, select the appropriate installation option: 

- Component install: Use a snippet that the website team places at a specific location on the website. 

- Full-page install: Use a complete, ready-to-host page for a dedicated concierge landing page. 

- 

Provide the selected script or page to the website team. 

- 

Have the website team install the script directly in the page code or through a tag manager. 

 NOTE 

Installation is typically handled by the website team, similar to adding an analytics or chat-tool tag. 

## Configure the surface 

After the script is installed, surface configuration controls the pages where the concierge appears. For example, you can configure the concierge to appear on product pages but not on a careers page. 

## Add a domain and page rules 

- 

Add a domain, such as blog.example.com . 

- 

Choose how paths on the domain should match. Available matching patterns include: 

- Any page under the domain. 

- Paths that start with a specified value. 

- Paths that end with a specified value. 

- An exact path match. 

- 

Combine multiple rules to define more precise page coverage. 

- 

Save the surface configuration. 

## Verify the deployment 

After the website team installs the script and the surface rules are saved, verify that: 

- The script is present on the intended website pages. 

- The concierge appears only on pages covered by the configured rules. 

- The concierge does not appear on excluded pages. 

- Visitor interactions generate activity data for the configured datastream. 

 TIP 

Test both an included page and an excluded page. This confirms that the surface rules are working as intended before the concierge is made broadly available.
