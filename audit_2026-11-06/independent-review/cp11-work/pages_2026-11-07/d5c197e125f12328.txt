## Build and test your first Brand Concierge 

Last update: October 2, 2026 

This article walks through creating a concierge and preparing it for review, from initial setup through sharing it for feedback. 

## Before you start 

Gather the following information before creating your first concierge. 

- The brand’s website URL: This is the only required input to create the first concierge. Composer reads it and drafts most other settings automatically. 

- Confirmation that access to Brand Concierge has already been granted: See User and Access Management . If login is not possible, that is an IT or administrator task and is not resolved in this guide. 

- Product-card information: For product cards in responses, prepare either an AEM Sites or Content AI connection, or a spreadsheet of products containing the name, description, image, and link for the Product Catalog. 

- Adobe Commerce details: For Adobe Commerce customers, obtain the environment ID, store codes, and API key from the commerce or IT team. 

- 15-30 minutes of uninterrupted time: Most of the setup involves reviewing and lightly editing AI-generated drafts rather than authoring content from scratch. 

## Step 1: Set up a concierge and test it in preview 

- Go to Manage a concierge and create a concierge using a website URL. 

- Test it in the live preview using a few representative visitor questions. 

## Step 2: Customize the brand experience 

- Refine the brand expression and brand profile drafted at creation. For more information, see Manage a concierge . 

- Review and adjust concierge instructions and guardrails. 

- Adjust tone and voice, visual style, and chat components to match brand requirements. 

## Step 3: Run evaluations 

- Go to Evaluate a concierge and create an evaluation set for each evaluation type: functional, out-of-scope, and safeguard. 

- Run the evaluations and review flagged results before proceeding. 

## Step 4: Create a shareable preview link 

- From Manage a concierge , generate a shareable link to the concierge’s current preview. 

- Share the link with stakeholders for feedback, without requiring them to have Composer access. 

Once the concierge has been customized, evaluated, and reviewed, see Deploy a concierge to make it available to real visitors, followed by the go-live checklist and Analyze concierge performance .
