## AEM Assets Integration for Commerce 

Last update: November 6, 2026 

- Topics: 

- Catalog management 

- Storefront 

- Configuration 

- CMS 

- Media 

- Integration 

CREATED FOR: 

- User 

The demand for personalized content is rapidly increasing while marketing budgets are under pressure. Retailers and brands are struggling to keep pace with the growing need for variations in product imagery, driven by regional, seasonal, and segment-specific requirements. 

Consider a retailer with 1,000 products. The number of required digital assets expands significantly when considering different regions, customer segments, and personalization efforts. This situation can lead to an overwhelming number of asset variations, reaching into the millions. 

 {width="700" modal="regular"}

The AEM Assets Integration addresses this challenge by automating asset management workflows. The integration dynamically links digital assets to the appropriate Adobe Commerce products and categories based on SKU or other key attributes. This process streamlines operations and enhances efficiency by enabling: 

- 

 Seamless Installation and Configuration – Merchandising teams and developers can quickly set up the integration using familiar Adobe tools and workflows. 

- 

 Dynamic Asset Updates – Product images and marketing assets automatically reflect the latest changes in AEM Assets, keeping storefronts accurate and relevant. 

- 

 Streamlined Catalog Management – Automates asset refresh and cleanup, minimizing manual effort and ensuring a consistent, well-maintained product catalog. 

- 

 Localized image alt text – Merchandisers can author alt text for each Commerce store view. The integration synchronizes the value to Commerce’s standard image Label field. 

- 

 Custom image roles – With AEM Assets Integration extension version 1.4.6 or later, custom image roles configured in AEM Assets are retained during synchronization, in addition to the four standard roles. See Custom automatic matching . 

- 

 Extension update notifications – With AEM Assets Integration extension version 1.4.6 or later, Commerce checks for new extension versions and notifies administrators in the Admin. See Check for extension updates . 

Alt-text localization does not change product-image assignment or gallery mapping. Store-view asset availability is a separate capability and is not covered by the alt-text workflow. 

## Requirements to use the integration 

To leverage this integration either with Product Visuals or AEM Assets , businesses must meet the following requirements: 

Product Visuals 

 [SaaS only]{class="badge positive" title="Applies to Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer projects only (Adobe-managed SaaS infrastructure)."} Active licenses for Adobe Commerce, Product Visuals powered by AEM Assets, and AEM Dynamic Media (These licenses are available out-of-the-box with Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer). 

AEM Assets 

 [SaaS only]{class="badge positive" title="Applies to Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer projects only (Adobe-managed SaaS infrastructure)."} Active licenses for Adobe Commerce, Adobe Experience Manager Assets, and AEM Dynamic Media . 

[PaaS only]{class="badge informative" title="Applies to Adobe Commerce on Cloud projects only (Adobe-managed PaaS infrastructure)."} Adobe Commerce 2.4.5+ 

- Adobe Commerce 2.4.5+. For details, see System requirements . 

 [SaaS only]{class="badge positive" title="Applies to Adobe Commerce as a Cloud Service and Adobe Commerce Optimizer projects only (Adobe-managed SaaS infrastructure)."} Adobe Experience Manager is provisioned with Adobe Experience Manager Assets as a Cloud Service 

The Adobe Commerce user configuring the integration must have access to the IMS Organization where the AEM Assets project is provisioned. 

## Key business benefits 

 No Additional Cost – This integration is provided free of charge for merchants who meet the licensing requirements.

 Official Adobe Solution – Developed, maintained, and fully supported by Adobe, ensuring stability and alignment with future platform enhancements.

 Adobe Managed Support Model – Adobe handles assistance and troubleshooting directly, providing reliable support and streamlined issue resolution.

 Adobe Storefront Builder capabilities – The digital asset management (DAM) solution allows the use of assets like images, videos, and other media on the Storefront Builder .

## Next steps 

The process to install and configure the AEM Assets integration depends on your Adobe Commerce deployment. In all cases, you first configure AEM Assets, then connect Commerce to it. 

To understand the namespace, metadata schema, and Commerce tab that the integration adds to your AEM Assets environment, review Commerce metadata in AEM Assets before you begin. 

For localized image alt text, see Localized alt text in AEM Assets metadata . For setup and synchronization instructions, see Configure the AEM Assets project and Configure the integration . 

Select your deployment to follow the required steps in order: 

Adobe Commerce as a Cloud Service 

[SaaS only]{class="badge positive" title="Applies to Adobe Commerce as a Cloud Service projects only (Adobe-managed SaaS infrastructure)."} 

- 

To support Commerce metadata, configure the AEM Assets project . On AEM release 2026.5.26309 and later, use the self-service onboarding ; on earlier releases, install the assets-commerce package manually. 

- 

 Configure IMS user permissions so the Asset Selector and the auto-populated Program ID and Environment ID fields are available. 

- 

 Configure the integration in the Commerce Admin . 

- 

Optional. Enable product-image display so a storefront powered by Edge Delivery Services renders AEM-managed product images. 

Adobe Commerce on Cloud (PaaS) 

[PaaS only]{class="badge informative" title="Applies to Adobe Commerce on Cloud projects only (Adobe-managed PaaS infrastructure)."} 

- 

To support Commerce metadata, configure the AEM Assets project . On AEM release 2026.5.26309 and later, use the self-service onboarding ; on earlier releases, install the assets-commerce package manually. 

- 

 Install Adobe Commerce packages to add the extension and generate the required credentials and connections. 

- 

 Configure IMS user permissions so the Asset Selector and the auto-populated Program ID and Environment ID fields are available. 

- 

 Configure the integration in the Commerce Admin . 

- 

Optional. Enable product-image display so a storefront powered by Edge Delivery Services renders AEM-managed product images.
