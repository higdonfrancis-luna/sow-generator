## Create an AEM site 

Last update: October 9, 2026 

- Applies to: 

- Experience Manager as a Cloud Service 

- Topics: 

- Edge Delivery Services 

CREATED FOR: 

- Beginner 

- Developer 

The AEM site is where the website’s content is edited, managed, and published from. To create an AEM site delivered via Edge Delivery Services and authored using Universal Editor, use the Edge Delivery Services with AEM authoring site template to create a new site on AEM Author. 

The AEM site is where the website’s content is stored and authored. The final experience is a combination of the AEM site content with the website’s code . 

Follow the detailed steps outlined in documentation to create a new AEM site. Below is a summarized list of the steps, including the values used in this tutorial. 

- 

 Create a new site in AEM Author. This tutorial uses the following site naming: 

- 

Site title: WKND (Universal Editor) 

- 

Site name: aem-wknd-eds-ue 

- The site name value must match the site path name added to paths.json . 

- 

 Import the latest template from the Edge Delivery Services with AEM authoring site template . 

- 

 Name the site to match the GitHub repository name and set the GitHub URL as the repository’s URL. 

## Publish the new site to preview 

After creating the site in AEM Author, publish it to the Edge Delivery Services preview making the content available to the local development environment . 

- Log in to AEM Author and navigate to Sites . 

- Select the new site ( WKND (Universal Editor) ) and click Manage Publications . 

- Choose Preview under Destinations and click Next . 

- Under Include Children Settings , select Include children , deselect other options, and click OK . 

- Click Publish to publish the site’s contents to preview. 

- Once published to preview, the pages are available on the Edge Delivery Services preview environment (the pages will not appear on the AEM Preview service).
