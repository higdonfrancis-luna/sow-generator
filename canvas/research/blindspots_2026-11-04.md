### Ad platforms (add now; cja)

- **Vendors:** Google Ads (V2), Meta Ads (Facebook, Instagram), Pinterest Ads, Snapchat Ads, TikTok Ads; any other platform through a CSV export into a summary dataset
- **Connects to:** cja; **plays:** cja, custom
- **How:** Experience Platform advertising sources authorize each ad account and provision paid media datasets that a CJA connection and data view report next to site conversions (Google Ads V2, Pinterest, Snapchat and TikTok are 'available as part of the Customer Journey Analytics SKU'). For any other platform, a daily or hourly export goes into a summary dataset on the XDM Summary Metrics schema, joined to event data by a campaign tracking code.
- **Partner services:** (1) Ad platform data into CJA: authorize the ad accounts (Google Ads developer token and manager login ID; TikTok needs a TikTok for Business developer app with Marketing API, TikTok approval and four permission groups), provision paid media datasets, add them to the connection, map tracking keys to site data. (3) Paid, organic and AI-referred traffic report in Workspace, next to BVCJ2. 8 / 16 / 32. Hours are planning assumptions; Adobe publishes none.

The first question a CMO asks is how it compares to paid media, and today the canvas has no place for ad spend. Ad data in CJA is a standard part of marketing analytics SOWs and comes with clear, billable setup work for each platform. It is included in the CJA SKU for the four named sources, so there is no license hurdle for the client.

### Data warehouse (copy, mirror or query in place) (add now; platform)

- **Vendors:** Copy (advanced enterprise sources): Snowflake, Google BigQuery, Amazon Redshift, Azure Databricks, Azure Synapse. Mirror (Data Mirror with change data capture): Snowflake, Google BigQuery, Azure Databricks. Query in place (Federated Audience Composition): Amazon Redshift, Azure Synapse, Databricks, Google BigQuery, Microsoft Fabric, Oracle, Snowflake, Teradata, Vertica.
- **Connects to:** rtcdp, ajo; **plays:** custom
- **How:** Three documented routes, which should be three options on the one box rather than one line: (1) advanced enterprise source connectors copy warehouse tables into Experience Platform datasets on a batch schedule; (2) Data Mirror brings row-level inserts, updates and deletes into relational schemas, which Journey Optimizer orchestrated campaigns need; (3) Federated Audience Composition queries the warehouse in place and saves the result as an external audience usable in Real-Time CDP and in Journey Optimizer Read Audience journeys.

Optional monthly dataflow monitoring 2 / 4 / 8 hours a month (RT06 already covers platform dataflow operations, so this should start off and show the overlap note). All hours are our planning estimates; Adobe publishes none.
